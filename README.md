# NYC Political Demographic Map

Interactive NYC political affiliation and demographic map prepared for GitHub Pages.

## Files

- `index.html` — the full interactive map
- `.nojekyll` — tells GitHub Pages not to process the site with Jekyll

## How to publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html` and `.nojekyll` to the repository root.
3. Go to **Settings** → **Pages**.
4. Under **Build and deployment**, choose:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Click **Save**.
6. Wait 1–3 minutes for GitHub Pages to publish the site.

## Notes

This map loads some public datasets live in the browser. It should be opened in Chrome, Edge, or Safari with internet access.
